##  Descripción

Aplicación móvil desarrollada colaborativamente en **Android Studio** como proyecto académico. Simula la compra de entradas de cine y la **gestión de asientos**, aplicando fundamentos de programación orientada a objetos en Java.

##  Funcionalidades

- Gestión y selección de asientos para funciones de cine.
- Flujo de compra de entradas de cine.
- Manejo de datos mediante lectura y escritura de archivos.

## Tecnologías y conceptos

- **Java** y **Android Studio**.
- **Programación orientada a objetos:** encapsulamiento y polimorfismo.
- **Manejo de excepciones**.
- **Lectura y escritura de archivos**.

##  Cómo ejecutar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Sam-ai06/App-cine-android-Studio.git
   ```
2. Abre la carpeta del proyecto Android (`PAR5_PROY2P_Villagomez_Miaca_Chichande`) en **Android Studio**.
3. Sincroniza el proyecto y ejecútalo en un emulador o dispositivo Android compatible.

También puedes encontrar una compilación de prueba en [`app-debug.apk`](./app-debug.apk).
